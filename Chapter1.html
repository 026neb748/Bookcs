Definition, Characteristics, and Application of Computer


Definition: An electronic device that accepts raw data, processes it according to stored instructions, produces useful information (output), and stores it for future use.

Characteristics: High speed, accuracy, diligence (does not get tired), high storage capacity, versatility, and automation.

Applications: Used in education, healthcare, banking, science and engineering, business, communication, and entertainment.

          
Evolution of Computer Technology


First Generation (Vacuum Tubes): Large size, high heat generation, used magnetic drums for memory and machine language.

Second Generation (Transistors): Smaller, faster, and more reliable than vacuum tubes; introduced assembly language and early high-level languages like FORTRAN.

Third Generation (Integrated Circuits - ICs): Replaced transistors with ICs, enabling keyboard/monitor interactions and operating systems.

Fourth Generation (Microprocessors): Thousands of ICs packed onto a single silicon chip (VLSI/ULSI), leading to personal computers and the internet.

Fifth Generation (Artificial Intelligence): Current and future technology focused on AI, parallel processing, voice recognition, and quantum computing.

   
Measurement Unit of Processing Speed and Storage Unit


Processing Speed: Measured in Hertz (Hz)—specifically Megahertz (MHz) or Gigahertz (GHz)—representing millions or billions of instruction cycles per second.

Storage Units: Base unit is a bit (0 or 1).

8 Bits = 1 Byte

1,024 Bytes = 1 Kilobyte (KB)

1,024 KB = 1 Megabyte (MB)

1,024 MB = 1 Gigabyte (GB)

1,024 GB = 1 Terabyte (TB)


Super, Mainframe, Mini, and Microcomputers


Supercomputers: Extremely powerful systems designed for massive scientific calculations, climate modeling, and nuclear simulation.

Mainframe Computers: Large, highly reliable systems used by corporations and governments for bulk data processing and critical transaction processing.

Minicomputers: Mid-sized multi-user computers suited for small to medium enterprises for specific tasks like industrial control or server management.

Microcomputers: Personal computers (desktops, laptops) designed for individual daily tasks, driven by a single microprocessor chip.


Mobile Computing and its Application


Definition: A technology that enables wireless transmission of data, voice, and video via a computer or any other wireless-enabled device without fixed physical links.

Applications: Mobile banking, GPS navigation, remote healthcare, mobile commerce (e-commerce), and real-time social communication.

Computer System and I/O Devices


Concept of Computer Architecture and Organization


Computer Architecture: The conceptual design and fundamental operational structure of a computer, focusing on hardware components visible to the programmer (e.g., instruction sets, addressing modes).

Computer Organization: How hardware components are interconnected and function operationally to realize the architecture (e.g., signals, memory controllers, bus interface types).


Components of Computer System


Input Unit: Captures raw data and sends it to the central processor.

Output Unit: Displays or renders processed data (information) to the user.

Processing Unit (CPU): Executes instructions, performs calculations, and coordinates data flow.

Memory Unit: Temporarily holds active programs, instructions, and data during processing.

Storage Unit: Stores files, operating systems, and media permanently for future retrieval.


Microprocessor


Basic Concepts: The central processing unit (CPU) built onto a single integrated circuit chip.

Clock Speed: The speed at which a CPU executes instructions, measured in Gigahertz (GHz).

Word Length: The number of bits a CPU can process in a single instruction cycle (e.g., 32-bit or 64-bit).

Components: Contains the Control Unit (CU), Arithmetic Logic Unit (ALU), and Registers.

Functions: Fetches instructions, decodes them, executes mathematical/logical operations, and manages system data movement.


Bus System


Data Bus: Bidirectional path carrying actual data between the CPU, memory, and peripheral components.

Address Bus: Unidirectional path carrying physical memory addresses that the CPU wants to read from or write to.

Control Bus: Carries command signals (e.g., Read, Write, Interrupt) from the CPU to coordinate hardware operations.


Primary Memory


Definition: Main internal memory directly accessible by the CPU to hold data and instructions currently being executed.

RAM (Random Access Memory): Volatile primary memory used for active system tasks.

SRAM (Static RAM): Uses transistors; extremely fast, used mainly as Cache memory.

DRAM (Dynamic RAM): Uses capacitors; requires constant refreshing, used for main system memory.

ROM (Read-Only Memory): Non-volatile memory containing permanent boot-up instructions (BIOS/UEFI).

PROM: Programmable ROM (written once).

EPROM: Erasable Programmable ROM (erased using UV light).

EEPROM: Electrically Erasable Programmable ROM (erased and rewritten electronically).

Cache: Ultra-fast static memory located near or inside the CPU to store frequently accessed data.

Buffer: A temporary holding area in memory used to compensate for speed differences between hardware devices during data transfers.


Secondary Memory


Definition: Non-volatile, long-term storage used to save user data, software, and files permanently.

Magnetic Disk: Mechanical storage using spinning magnetic plates (e.g., Hard Disk Drive / HDD).

Flash Memory: Non-mechanical, solid-state electronic storage with fast access speeds (e.g., SSD, SD Cards).

Optical Disk: Storage medium written and read using laser beams (e.g., CDs, DVDs, Blu-ray).

External Storage Device: Portable enclosures connected externally for off-site data backup.

Memory Stick: Compact, portable flash storage media (such as USB thumb drives or proprietary flash cards) plugged directly into expansion interfaces.


Input Devices


Keyboard: Primary text and command input device using physical key switches.

Mouse: Handheld pointing device that moves an onscreen cursor.

Scanner: Converts physical documents and pictures into digital image files.

Light Pen: Light-sensitive wand used to draw directly on CRT screens or select screen options.

OMR (Optical Mark Reader): Detects shaded pencil or ink marks on pre-printed forms (used for standardized tests).

OCR (Optical Character Recognition): Software/hardware technology converting scanned images of handwritten/printed text into editable text data.

BCR (Barcode Reader): Optical scanner that reads printed barcodes on products to retrieve catalog details.

MICR (Magnetic Ink Character Recognition): Reads special magnetic ink characters printed on bank checks for secure document validation.

Touch Screen: Display panel acting as both input and output by sensing finger taps or gestures.

Microphone: Audio input hardware converting sound waves into digital audio signals.

Digital Camera: Captures photographs and video as digital data onto internal flash storage.


Output Devices


Monitor: Primary visual display terminal.

LCD (Liquid Crystal Display): Uses liquid crystals sandwiched between polarizing filters, backlit by CCFLs.

LED (Light Emitting Diode): Enhanced LCD display using energy-efficient LEDs for backlighting.

Printer: Hard-copy output device that transfers digital content onto physical paper.

Dot Matrix: Impact printer that forms characters using physical pins striking an inked ribbon.

Inkjet: Non-impact printer that sprays tiny droplets of liquid ink onto paper.

Laser: High-speed non-impact printer using a laser beam and electrostatic toner powder.

Speaker: Audio output device converting digital audio signals into audible sound waves.


Hardware Interfaces


Parallel Port: Legacy wide multi-pin interface used historically for older printers; transmits multiple data bits simultaneously.

Serial Port: Legacy interface transmitting data sequentially one bit at a time over a single wire pair.

USB Ports (Universal Serial Bus): Standard plug-and-play connection standard for connecting peripherals, supporting high-speed data transfer and power delivery.

HDMI (High-Definition Multimedia Interface): Modern compact digital cable standard delivering simultaneous high-definition video and audio.

Expansion Slots: Internal motherboard sockets (e.g., PCIe) allowing users to insert dedicated hardware expansion cards like GPUs, Wi-Fi adapters, or sound cards.
